# 🎓 ប្រព័ន្ធគ្រប់គ្រងសិស្ស និងវត្តមាន (សម្រាប់លោកគ្រូ-អ្នកគ្រូ)

ប្រព័ន្ធគ្រប់គ្រងសិស្ស និងវត្តមានកម្រិតស្តង់ដារ សម្រាប់លោកគ្រូ-អ្នកគ្រូប្រើប្រាស់ផ្ទាល់ខ្លួន គាំទ្រការគ្រប់គ្រងថ្នាក់រៀនច្រើន ($n$ ថ្នាក់) ដំណើរការបាន **Offline 100%** ដោយមិនចាំបាច់ភ្ជាប់អ៊ីនធឺណិត និងរក្សាទុកទិន្នន័យលើកុំព្យូទ័រដោយស្វ័យប្រវត្តិ។

---

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

### ១. 📊 ផ្ទាំងគ្រប់គ្រងរួម (Dashboard)
- ស្ថិតិរួម៖ ចំនួនសិស្សសរុប (ស្រី/ប្រុស), ចំនួនថ្នាក់រៀន ($n$ ថ្នាក់), អត្រាវត្តមានថ្ងៃនេះ (មក, ច្បាប់, ឥតច្បាប់, យឺត)។
- **ប្រអប់ដាស់តឿនសិស្សប្រឈម (High Absence Alert)**៖ ជូនដំណឹងសិស្សដែលអវត្តមានឥតច្បាប់ចាប់ពី **៣ ដង** ឡើងទៅភ្លាមៗ ជាមួយនឹងប៊ូតុងចុច **«ចេញលិខិតផ្លូវការ»** ដោយផ្ទាល់!

### ២. 🏫 ការគ្រប់គ្រងថ្នាក់រៀនច្រើន ($n$ ថ្នាក់)
- បង្កើត កែប្រែ និងលុបថ្នាក់រៀនបានដោយសេរី (ឧទាហរណ៍៖ ថ្នាក់ទី ៧ ក, ៨ ខ, ១០ វិទ្យាសាស្ត្រ...)។
- ប្តូរមើលថ្នាក់សកម្ម ឬមើលថ្នាក់ទាំងអស់ (All Classes) បានរហ័សនៅលើរបារខាងលើ (Navbar)។
- បង្ហាញស្ថិតិសិស្សតាមបន្ទប់រៀន និងកម្រិតថ្នាក់។

### ៣. 👥 ពត៌មានសិស្ស (Student Profiles & Directory)
- កត់ត្រាព័ត៌មានលម្អិត៖ លេខរៀង, អត្តលេខ, ឈ្មោះខ្មែរ-ឡាតាំង, ភេទ, ថ្ងៃខែឆ្នាំកំណើត, ទីកន្លែងកំណើត, អាសយដ្ឋាន។
- ព័ត៌មានអាណាព្យាបាល៖ ឈ្មោះឪពុក/ម្តាយ, មុខរបរ, ទំនាក់ទំនង, លេខទូរស័ព្ទ (ចុច Call បានភ្លាមៗ)។
- មុខងារ **ទាញចេញជា Excel (.xlsx)**, **ទាញយកគំរូ Excel**, និង **នាំចូលពី Excel (Import)**។
- **បោះពុម្ពបញ្ជីរាយនាមសិស្សផ្លូវការ** (មានក្បាលលិខិតជាតិ និងក្រសួងអប់រំ)។

### ៤. 📅 វត្តមានសិស្ស (Attendance Tracking)
- **ស្រង់វត្តមានប្រចាំថ្ងៃ (Daily Attendance)**៖
  - ជម្រើសកាលបរិច្ឆេទ និងវេន (ព្រឹក / រសៀល)។
  - ស្ថានភាព ៤ ប្រភេទ៖ **មក (បៃតង)**, **ច្បាប់ (លឿង)**, **ឥតច្បាប់ (ក្រហម)**, **យឺត (ខៀវ)**។
  - ប៊ូតុង **«កត់វត្តមានទាំងអស់ (មក)»** សម្រាប់កត់ត្រាលឿនក្នុងពេលតែ ១ វិនាទី!
  - ប្រអប់កត់ត្រាមូលហេតុអវត្តមាន។
- **តារាងស្រង់វត្តមានប្រចាំខែ (Monthly Matrix)**៖
  - បង្ហាញវត្តមានថ្ងៃទី ១ ដល់ ៣១ ក្នុងតារាងតែមួយ។
  - គណនាផលបូកអវត្តមាន (មានច្បាប់, ឥតច្បាប់, សរុប) ស្វ័យប្រវត្តិ។
  - បោះពុម្ពតារាងវត្តមានប្រចាំខែផ្លូវការ។

### ៥. 📜 សម្រង់អត្ថបទ & មេរៀន (Lesson Extracts & Quotes)
- ឃ្លាំងផ្ទុកសម្រង់ឯកសារ៖
  - អត្ថបទអាន និងអក្សរសិល្ប៍ខ្មែរ (ឧ. រឿងទុំទាវ...)
  - ខ្លឹមសារមេរៀនសង្ខេប (វិធានវេយ្យាករណ៍, រូបមន្តគណិតវិទ្យា)
  - អត្ថបទសរសេរតាមអាន
  - ពាក្យស្លោក និងគតិបណ្ឌិតអប់រំ (សម្តេចព្រះសង្ឃរាជ ជួន ណាត)
- មុខងារស្វែងរកតាមស្លាក (Tags), ចម្លងខ្លឹមសារ (Copy to clipboard) និងបោះពុម្ពឯកសារ។

### ៦. ✉️ លិខិតផ្លូវការសម្រាប់ផ្ញើទៅអាណាព្យាបាល (Official Letters)
- ទម្រង់លិខិតរដ្ឋបាលអប់រំផ្លូវការ៖
  - ក្បាលលិខិត៖ **«ព្រះរាជាណាចក្រកម្ពុជា ជាតិ សាសនា ព្រះមហាក្សត្រ»** និង **«ក្រសួងអប់រំ យុវជន និងកីឡា»**។
  - លេខលិខិតរដ្ឋបាល, កាលបរិច្ឆេទធ្វើនៅ...។
  - បំពេញទិន្នន័យសិស្ស, ចំនួនថ្ងៃអវត្តមានឥតច្បាប់, កាលបរិច្ឆេទថ្ងៃអវត្តមានជាក់ស្តែងដោយស្វ័យប្រវត្តិ។
  - កាលវិភាគណាត់ជួបអាណាព្យាបាល (ថ្ងៃ និងម៉ោង)។
  - ហត្ថលេខាគ្រូបន្ទុកថ្នាក់ និងការឯកភាពពីនាយកសាលា។
- **បោះពុម្ពលើក្រដាស A4 ស្អាតបាត ១០០%** តាមស្តង់ដាររដ្ឋបាលកម្ពុជា។

### ៧. 🎯 ផែនការគ្រូ ១ ឆ្នាំ (Teacher's Master Plan)
- បំណែងចែកកម្មវិធីបង្រៀនប្រចាំឆ្នាំ (ឆមាសទី ១ និង ឆមាសទី ២)។
- បែងចែកតាមខែ (តុលា ដល់ កក្កដា), សប្តាហ៍, ជំពូក, ចំណងជើងមេរៀន, ចំនួនម៉ោង, វត្ថុបំណង, សម្ភារៈឧបទេស, និងការវាយតម្លៃ។
- តាមដានវឌ្ឍនភាព (% សម្រេចបាន, មេរៀនដែលបានបញ្ចប់, កំពុងអនុវត្ត, មិនទាន់អនុវត្ត)។
- បោះពុម្ពផែនការបង្រៀនប្រចាំឆ្នាំ។

### ៨. 💎 ធាតុបន្ថែមពិសេស (Bonus Features)
- 🏆 **ស្រង់ពិន្ទុ & ចំណាត់ថ្នាក់ (Grades & Ranking)**៖ បញ្ចូលពិន្ទុមុខវិជ្ជា, គណនាផលបូក, មធ្យមភាគ, និទ្ទេស (A, B, C, D, E, F) និងចំណាត់ថ្នាក់ (លេខ១, លេខ២, លេខ៣...) ស្វ័យប្រវត្តិ។
- ⏰ **កាលវិភាគបង្រៀន (Weekly Timetable)**៖ កាលវិភាគប្រចាំសប្តាហ៍ ច័ន្ទ ដល់ សៅរ៍។
- 💾 **Backup & Restore ទិន្នន័យ (Database Security)**៖
  - ទាញយក Backup ជាឯកសារ `.json` ដោយចុចតែម្តង។
  - ស្តារ Backup ឡើងវិញដោយសុវត្ថិភាព។
  - ដំណើរការលើ IndexedDB (Dexie) រក្សាទុកទិន្នន័យក្នុង Browser ដោយមិនបាត់បង់ទោះបិទកុំព្យូទ័រក៏ដោយ។

## 🚀 របៀបបើកដំណើរការកម្មវិធី (Getting Started)

### ១. ដំឡើងកញ្ចប់តម្រូវការ (បើទើប Clone ថ្មី)
```bash
npm install
```

### ២. ដំណើរការប្រព័ន្ធ (Development Mode)
```bash
npm run dev
```
បន្ទាប់មកបើក Browser ទៅកាន់អាសយដ្ឋាន៖ `http://127.0.0.1:5173/`

### ៣. បង្កើតជាកញ្ចប់ Production Build
```bash
npm run build
```

## 🛠️ បច្ចេកវិទ្យាប្រើប្រាស់ (Tech Stack)
- **React 19 + TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Dexie.js (IndexedDB)** សម្រាប់ Local Offline Database
- **SheetJS (xlsx)** សម្រាប់នាំចេញ/នាំចូល Excel
- **Lucide React Icons**
- **Khmer Fonts**: Kantumruy Pro, Moul, Battambang, Siemreap (Google Fonts)
